# Authorized use

P-BitM is intended only for controlled security assessments, training
environments, and research systems where the operator has explicit written
authorization.

Before use, document:

- systems, domains, recipients, and accounts in scope;
- permitted techniques and data categories;
- assessment start and end times;
- responsible operators and escalation contacts;
- emergency-stop conditions;
- evidence access, retention, and deletion requirements.

Do not infer authorization from technical reachability, employment, ownership
of unrelated infrastructure, or possession of credentials.

The project maintainers do not grant permission to test third-party systems.
Operators remain responsible for legal, contractual, privacy, and regulatory
obligations.
