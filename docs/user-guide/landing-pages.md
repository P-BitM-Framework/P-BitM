# Landing pages

Landing pages are reusable HTML documents selected by campaigns before the
browser session is established.

From **Landing Pages** you can create, edit, clone, import, export, and delete
pages. Name and description are library metadata; `content` is the rendered
HTML.

## Safe authoring

- Treat imported HTML as active content.
- Review scripts, forms, remote resources, and redirects before saving.
- Use only assets and domains approved for the exercise.
- Do not embed administrator credentials, internal API keys, or tracking IDs.
- Test the page with designated non-production recipients.

The campaign target URL is configured separately in the campaign wizard and
must be a valid HTTP or HTTPS URL.
