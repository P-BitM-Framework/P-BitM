# Target lists

Target lists group approved recipients for campaigns. A list also carries the
name of the company being tested (set from the list's own edit dialog, not
per target), since every target in a list belongs to the same engagement.

## Contact fields

Each target has an email address and may include first name, last name,
position, department, and custom fields. Email addresses are validated and
normalized by the backend.

## Managing targets

From **Target Lists** you can:

- create and rename lists;
- add or edit individual targets;
- import targets in bulk;
- select and delete multiple targets;
- export a list as CSV.

Review bulk-import results before campaign launch. Invalid rows are reported
instead of being silently accepted.

## Data minimization

Import only fields required by the approved exercise. Do not use production
address books as general test data, and delete exports according to the
engagement retention policy.
