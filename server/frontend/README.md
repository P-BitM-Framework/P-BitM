# P-BitM frontend

Vue dashboard built with Vite, Pinia, Vue Router, PrimeVue 4, and Vitest.

```bash
npm ci
npm run dev
npm test
npm run build
```

Use the full development Compose stack when testing frontend/backend routing
and TLS.
